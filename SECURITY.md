# Security Policy

## Supported Versions

Only the latest release of Heimdall receives security fixes. Older releases
are not actively maintained.

| Version | Supported |
| ------- | --------- |
| 1.4.x   | ✅        |
| < 1.4   | ❌        |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

To report a vulnerability, email Benjamin Dobell at
**benjamin.dobell@glassechidna.com.au** with the subject line
`[Heimdall] Security Vulnerability`.

Include as much detail as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected versions (check `heimdall version`)
- Any suggested mitigations, if known

You can expect an acknowledgement within a few days. If the vulnerability is
confirmed, a fix will be targeted for the next release. You will be credited
in the release notes unless you prefer to remain anonymous.
